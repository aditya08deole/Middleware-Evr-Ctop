Scheduler Settings

Controls how often the pipeline polls every device (ThingSpeak) and checks EMQX buffers. Applies to the live scheduler immediately — no restart needed.

E.g. 0.25 = every 15 seconds. 1-1440 minutes.

CTOP Hosts

The "middle part" of a CTOP URL (e.g. https://ctop.iiit.ac.in or a dev/staging server) — register every host here once, then on a device's page pick a host + its node path instead of retyping the full URL. A device still sends to every host it targets (plus its original URL fields) — if one host is down, delivery to the others is unaffected. Repointing a host here (e.g. if an address changes) updates every device that references it, with no code change.
